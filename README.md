# Which Card?

A single-page app: save the names of your credit cards, paste a product link, and get the best card to use, with the reasoning, tradeoffs and options.

**Live:** https://mikedegroot.github.io/PickACard/

- Your card list stays in your browser and can be saved to or opened from a `my-cards.json` file. It stores names and notes only, never card numbers.
- Research runs through the Anthropic API with web search. Enter your own API key in Settings; it goes straight from your browser to Anthropic.
